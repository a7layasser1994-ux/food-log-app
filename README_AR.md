# تطبيق سجل أكلي - مشروع Android يعمل دون إنترنت

هذا مشروع Android يضم نسخة HTML داخل التطبيق. لا توجد صلاحية INTERNET في التطبيق، وتم حذف تحميل خط Google الخارجي. استرجاع النسخة الاحتياطية يدعم اختيار ملف JSON من مدير الملفات أو لصق نص النسخة.

## بناء APK من الهاتف فقط عبر GitHub Actions

1. أنشئ مستودعًا جديدًا (Repository) على GitHub من متصفح الهاتف.
2. ارفع محتويات هذا المجلد إلى المستودع مع الحفاظ على المجلدات كما هي، خصوصًا `.github/workflows/build-apk.yml` و`app/src/main/assets/index.html`.
3. افتح تبويب Actions في المستودع.
4. اختر `Build سجل أكلي APK` ثم `Run workflow` إذا لم يبدأ البناء تلقائيًا بعد الرفع.
5. بعد نجاح العملية، افتح نتيجة التشغيل (workflow run)، وانزل إلى Artifacts، وحمّل `sajl-akli-debug-apk`.
6. فك ضغط الملف المحمّل، ثم افتح `app-debug.apk` وثبّته. قد يطلب Android السماح بالتثبيت من هذا المصدر.

> يمكن تنفيذ البناء على خوادم GitHub؛ لا تحتاج إلى Android Studio أو كمبيوتر. قد تحتاج إلى تسجيل الدخول إلى GitHub واتصال إنترنت أثناء رفع الملفات والبناء والتنزيل فقط.

## ملاحظات

- بيانات الأكل تُحفظ باستخدام `localStorage` داخل WebView، مع تفعيل DOM Storage.
- استرجاع النسخة الاحتياطية يدعم اختيار ملف JSON عبر مدير ملفات Android، كما يدعم لصق النص يدويًا.
- لا يمنح التطبيق صلاحية الإنترنت، ولا يحتاج إلى اتصال أثناء الاستخدام.
- خذ نسخة احتياطية من داخل الإعدادات قبل حذف التطبيق أو مسح بياناته أو تغيير الهاتف.
- خط Cairo لم يعد يُحمّل من Google؛ سيُستخدم خط النظام البديل حتى يعمل التطبيق بالكامل دون إنترنت.
- الملف الناتج من هذا المسار Debug APK للتثبيت الشخصي والاختبار، وليس إصدارًا مخصصًا للنشر التجاري على Google Play.
